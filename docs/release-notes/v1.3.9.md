# NESTNOTE v1.3.9 — Release notes draft

> **Publication gate:** Draft only. Publish after the v1.3.9 release candidate passes CI and the required device/release checklist. The active audit still records inline playback while editing and wallpaper-import integration as items requiring confirmation.

## Improvements
- Keep voice-note playback inline with the note rather than opening a separate player or covering the page.
- Make voice attachments easier to identify with recording labels and clearer player/waveform accessibility descriptions.
- Keep voice-note marker handling from exposing internal attachment identifiers as ordinary note text.
- Preserve note text and the selected plain-text/Markdown format while handling voice attachments.

## Bug fixes
- Fix voice-player layout so recording labels, waveform, and seek controls do not overlap.
- Fix the note-format menu build failure caused by a reference to an unavailable Material icon.
- Persist plain-text versus Markdown format and default older notes safely to plain text.
- Add regression tests for inline and adjacent voice markers, text preservation, and marker removal.

## Privacy and compatibility
- Notes and voice attachments remain local-first; there is no account or cloud sync.
- Voice attachments remain excluded from the current JSON backup/restore format. Exported JSON backups contain plaintext note data and should be stored securely.

## Not included until merged and validated
- Encrypted unique-link sharing and QR-code sharing.
- Wallpaper import, unless editor integration and tests are confirmed complete.

## Verification before publishing
- Confirm CI passes for the exact release tag.
- Verify production APK signing certificate, installation and upgrade behavior.
- Complete and record required device checks, including inline voice playback while editing and wallpaper import.
- Publish the final notes to the GitHub Release and ensure the documentation/F-Droid changelog links resolve.
