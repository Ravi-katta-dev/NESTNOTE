# NESTNOTE 1.4.5

Release version: 1.4.5

This note records the project-maintained release baseline. The GitHub Releases page remains the source of truth for published APK assets and release publication metadata.

## Highlights
- Local-first note capture, editing, search, categorization, pinning, archiving, restore, and configurable Home layout.
- Presentation-only text zoom for editor and saved-note reader.
- Read-only external Markdown viewing with a separate zoom preference.
- Offline Text Toolbox under More → Power tools.
- Local backup and restore with validation and merge safeguards.
- Private Vault password access and optional biometric flow, subject to device-level validation and the documented security boundaries.

## Compatibility and limitations
- Minimum Android API: 26.
- Compile/target SDK: 36.
- No cloud sync or account-based storage.
- Reminder date/time values are metadata; notifications are not implemented.
- Historical release behavior: JSON backups were plaintext. The current branch removes that feature; current portability uses password-protected encrypted archives and excludes Private Vault notes and voice attachments.

## Verification
Consult the corresponding GitHub Release and CI run for the exact published artifact and validation evidence. Do not infer physical-device validation, biometric recovery validation, or signing verification from a successful compilation alone.
