# NESTNOTE 1.4.7

Release version: 1.4.7

This note records the project-maintained release candidate. Publication and artifact metadata must be verified on the tagged commit. The GitHub Releases page remains the source of truth for published APK assets and release publication metadata.

## Highlights
- Performance: frame skipping eliminated at the source — the theme `ColorScheme` is rebuilt only when the theme changes, note wallpapers decode off the main thread with downsampling and a shared LRU cache, and editor-derived work is debounced instead of running full-body scans per keystroke.
- Performance: voice playback notifications refresh on a one-second loop, idle voice players no longer run always-on animations, and draft flushes no longer run encoding + fsync on the main thread during editor close.
- Performance: dashboard statistics are computed once per data change; note cards share one date formatter; lazy lists declare `contentType`.
- Interface: complete Material 3 colour foundation for warm light/dark schemes, opaque tonal accent palettes, and a first-class dark skin with 15 deep-toned note tints and dark-aware note cards.
- Interface: tonal category chips and gradient wallpaper scrims on note cards, Material 3 date/time pickers for reminders, refreshed dashboard hero with stat pills, pill-shaped search field, and actionable empty states.
- Local-first note capture, editing, search, categorization, pinning, archiving, restore, and configurable Home layout carried forward from 1.4.6.
- Presentation-only text zoom for editor and saved-note reader.
- Read-only external Markdown viewing with a separate zoom preference.
- Offline Text Toolbox under More → Power tools.
- Local backup and restore with validation and merge safeguards.
- Private Vault password access and optional biometric flow, subject to device-level validation and the documented security boundaries.

## Compatibility and limitations
- Minimum Android API: 26.
- Compile/target SDK: 36.
- No cloud sync or account-based storage.
- Reminder date/time values are metadata; notifications are not implemented.
- Portable note transfer uses password-protected encrypted archives, which exclude Private Vault notes and voice attachments.
