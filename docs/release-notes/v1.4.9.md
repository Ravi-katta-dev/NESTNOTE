# NESTNOTE 1.4.9

Release version: 1.4.9 (versionCode 10409)

This note records the project-maintained release candidate. Publication and artifact metadata must be verified on the tagged commit. The GitHub Releases page remains the source of truth for published APK assets and release publication metadata.

## Highlights
- Security: fingerprint unlock for call-recording folder management — enabling or disabling auto-import and changing the source folder can now be authorized with a strong biometric when enrolled. Both password and fingerprint paths converge on one action handler and require the CryptoObject-bound vault key unwrap before any change.
- Reliability: 100 MiB voice imports no longer crash on playback. Encrypted payloads read into an exactly-sized buffer and decrypt in place (~2× peak memory instead of ~4×), with `android:largeHeap` declared for the encrypted-audio use case.
- Editor format fixes: italic no longer deletes intraword underscores (`snake_case_word` is safe) and now uses asterisk markers that render correctly inside words; strikethrough and inline code convert a plain note to Markdown like Bold/Italic instead of inserting literal markers; link-to-note uses the same shared conversion path.
- Settings UX: search shows how many sections match (with a hint when nothing matches), the list resets to the top while searching instead of landing on blank space, and a version footer shows the installed version at the bottom of Settings.
- Voice import: the editor picker accepts `application/ogg` and `application/x-flac` recordings, and failed call-recording imports offer a Dismiss action instead of retrying forever.
- Reminders: denying notification permission now shows an inline warning in the reminder time picker (OI-1) instead of failing silently.
- Carried forward from 1.4.7: performance refresh (cached theme scheme, off-main-thread wallpaper decode, debounced editor derivation), Material 3 colour foundation, call-recording encrypted import, Private Vault with optional biometric enrollment.

## Compatibility and limitations
- Minimum Android API: 26.
- Compile/target SDK: 36.
- No cloud sync or account-based storage.
- Fingerprint folder unlock requires an enrolled Private Vault biometric and a device with strong biometrics.
- Portable note transfer uses password-protected encrypted archives, which exclude Private Vault notes and voice attachments.
