# NESTNOTE v1.3.11 — Release notes

**Release record:** Current for the v1.3.11 branch prepared by PR #76.  
**Publication:** A stable `v1.3.11` tag and successful release workflow are still required before this version is available as a published release.

## Fixed

- Corrected editor text contrast on dark surfaces by using surface luminance and theme-provided foreground colors.
- Improved Markdown blockquote and horizontal-rule preview rendering while keeping raw HTML-like content inert.
- Preserved meaningful whitespace, indentation, trailing-newline semantics, and LF/CRLF/lone-CR line endings in text conversion and list operations.
- Improved cursor and reversed-selection remapping after line edits.
- Hardened inline-format toggles and checklist/bullet transitions, including indentation, Enter behavior, and mixed line endings.
- Restricted actionable Markdown preview links to `http`, `https`, and `mailto` schemes.
- Improved accessibility touch-target sizing and standalone Markdown heading semantics for preview segments.

## Markdown renderer and link insertion

PR #74 proposes replacing the regex-based Markdown preview preprocessor with Markwon's CommonMark-based Android renderer, adding task-list and strikethrough support, and hardening Markdown link-label escaping and cursor placement.

**Merge boundary:** PR #74 is still open as a draft and its CI/integration behavior has not been verified. Those changes are follow-up work, not claimed as merged or shipped in this release record.

## Tests and engineering

- Regression coverage covers Markdown rendering, formatting toggles, list/checklist transitions, link escaping and cursor placement, line-ending preservation, and safe-link handling.
- Editor integration coverage includes save/recovery, discard/reopen, preview/edit switching, formatting actions, link insertion, note switching, and Activity recreation.
- The repository includes CI workflow coverage for Android emulator UI tests; emulator execution remains separate from required CI.
