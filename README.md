# NESTNOTE

A responsive notes workspace inspired by the supplied mobile UI reference.

## Run locally
Open `index.html`, or run `python -m http.server 8000` and visit http://localhost:8000.

## Features
- Create, edit, delete, and pin notes
- Search notes and filter by category
- Reminder metadata and category management
- Light/dark theme and responsive layout
- Browser localStorage persistence

## Product roadmap
1. Add authentication and secure user accounts.
2. Add database-backed storage and cross-device sync.
3. Implement scheduled notifications and reminders.
4. Add automated tests, accessibility checks, and CI/CD.

This first version is a front-end prototype; reminders are stored locally and do not send notifications.
